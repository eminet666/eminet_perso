Sketchfab : Collection "Classical Busts" du Fitzwilliam Museum avec Euripide, Platon (téléchargeables en 3D haute qualité, scans réels).​
Printables.com : Buste de Platon (STL gratuit, original).​
CGTrader : Pythagore (scan 3D, STL/OBJ/FBX, adapté impression 3D).​
Open3DModel : Statues grecques antiques (gratuits, divers formats incl. STL).

Voici comment les retrouver précisément :
    - Cherche “Euripides 3D Printable Euripides Scan the World MyMiniFactory” : tu tomberas sur un buste scanné (projet Scan the World), généralement téléchargeable en STL ou convertible depuis le format proposé.​
    - Cherche “Euripides 3d stl model for CNC for3d.ru” : ce site propose un modèle de buste d’Euripide au format STL, plutôt pensé pour CNC mais utilisable en impression 3D après vérification des dimensions/détails.​
    - Utilise un méta‑moteur de modèles 3D comme Yeggi avec la requête “euripides” pour lister les différents STL disponibles (gratuits ou payants) sur plusieurs plateformes (Etsy, MyMiniFactory, etc.).​
